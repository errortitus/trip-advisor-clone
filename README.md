✈️ Tripadvisor Homepage Clone
A responsive, pixel-perfect clone of the Tripadvisor homepage built using Pure HTML5 and Custom CSS3. This project demonstrates standard front-end development practices, clean layout structure using BEM methodology, interactive elements, CSS animations, and full responsiveness across mobile, tablet, and desktop screens.
---
📌 Features
Sticky Navigation Bar: Logo, search bar, language/currency indicator, hoverable "Trips" popup menu, and profile actions.
Category Filter Bar: Clean interactive pill buttons for Hotels, Things to Do, Restaurants, Flights, and Vacation Rentals.
Animated Hero Banner: Keyframe `@keyframes zoom` animation showcasing featured travel offers.
Top Destinations & Popular Places: Card grid layout with hover elevation animations, pricing tags, and star ratings.
Trending Travel Experiences: Responsive tag layout for quick discovery.
Traveler Reviews Section: Real traveler feedback cards with ratings, user avatars, and smooth hover state transitions.
Multi-column Footer: Modern dark-themed footer with navigation links and copyright details.
Fully Responsive Design: Custom media queries tailored for desktop, tablet ($<800\text{px}$), and mobile ($<600\text{px}$) devices.
---
🛠️ Technologies Used
HTML5: Semantic HTML structure
CSS3: Custom CSS Flexbox, `@keyframes` animations, CSS variables, and Media Queries
Google Fonts: `Gabarito` font family
Font Awesome (v6.4.0): Icon library for UI elements

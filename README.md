# 🌍 Tripadvisor Homepage Clone

A responsive, clean, and modern front-end replica of the **Tripadvisor** landing page. This project is built using semantic **HTML5**, custom **CSS3** (Flexbox & BEM methodology), smooth `@keyframes` animations, and **Font Awesome** icons.

---

## 🌟 Features

- **Sticky Navigation Bar:** Includes custom brand logo, search bar, currency indicator (`INR`), action icons, and responsive layout.
- **Category Filter Pills:** Quick navigation options for Hotels, Things to Do, Restaurants, Flights, and Vacation Rentals with dynamic hover states.
- **Hero Banner & Custom Animations:** Features an animated offer card using CSS `@keyframes zoom` and realistic box shadows.
- **Destination & Popular Cards:** Responsive card grid/flexbox displaying handpicked destinations with star ratings, total review counts, original vs. discounted pricing, and hover elevation effects.
- **Trending Travel Tags:** Interactive filter tags highlighting popular activities such as Scuba Diving, Mountain Trekking, and Beach Resorts.
- **Traveler Reviews Section:** Clean cards layout featuring user avatars, destination details, star ratings, review dates, and testimonials.
- **Footer Section:** Multi-column navigation links with brand copyright details.
- **Mobile Responsive:** Integrated CSS media queries ensuring seamless UI adjustment on tablets and smartphones (hiding desktop nav items and triggering mobile hamburger menu styling).

---

## 🛠️ Tech Stack & Concepts Used

* **HTML5:** Semantic markup structure (`div`, `header`, `footer`, etc.)
* **CSS3:** Custom styling, Flexbox layout design, Keyframe animations, and Media Queries
* **BEM Methodology:** Block-Element-Modifier naming convention (e.g., `.review-card__header`, `.sales-image__offer`)
* **Font Awesome (v6):** Vector icons for search, travel categories, ratings, and navigation buttons
